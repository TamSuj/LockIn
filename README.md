# LockIn

A minimal, cute Pomodoro timer app with a penguin theme 🐧

## Features

- **Fixed Pomodoro Cycle**: 25-minute Focus sessions, 5-minute Short Breaks, and a Long Break after every 4 Focus cycles
- **Baby Blue Theme**: Beautiful, calming baby blue color scheme
- **Cute Penguin Design**: Minimal SVG penguin character that floats gently
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Single-File App**: Everything in one HTML file - no dependencies or build process
- **Simple Controls**: Just Start/Pause - no distractions
- **Visual Progress**: Cycle dots show your progress through the 4 Focus sessions

## Usage

Simply open `index.html` in any modern web browser. No installation or setup required!
